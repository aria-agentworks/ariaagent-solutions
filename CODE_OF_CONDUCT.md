# Code of Conduct

## Our standard

This project should be practical, respectful, and welcoming.

Examples of positive behavior:

- Respectful feedback and discussion
- Clear technical disagreement without personal attacks
- Sharing context that helps other contributors succeed
- Assuming good intent while still being honest and direct

Examples of unacceptable behavior:

- Harassment or discriminatory language
- Trolling or repeated bad-faith participation
- Publishing private information without permission
- Hostile or abusive review behavior

## Enforcement

Maintainers may remove comments, issues, pull requests, or other contributions that violate this code of conduct.

## Reporting

Report problems privately through the maintainer contact channels available on GitHub rather than escalating in public threads.
