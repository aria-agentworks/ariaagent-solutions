# Roadmap

## Near term

- Improve local setup so first run succeeds with fewer manual steps
- Add health checks for the Brain, Hands, and Mouth services
- Tighten environment validation for provider credentials and required endpoints
- Document the expected data contracts between pipeline stages

## Next

- Add richer campaign monitoring views in the operator dashboard
- Support approval queues and human-in-the-loop checkpoints
- Add reusable workflow presets for common ad campaign types
- Expand logging and failure recovery across the pipeline

## Later

- Multi-tenant workspace support
- Better provider abstraction for creative generation and deployment
- Evaluation loops for concept quality and campaign performance
- Hosted deployment guides for production operator teams
