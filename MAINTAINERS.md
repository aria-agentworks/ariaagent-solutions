# Maintainers

## Primary maintainer

- Aria Agentworks

## Maintenance policy

- The repository is under active development.
- Bug reports with clear reproduction steps are prioritized first.
- Pull requests should stay scoped to one improvement or fix.
- Security issues should be reported privately as described in [SECURITY.md](SECURITY.md).

## Contribution priorities

- Dashboard reliability and operator workflows
- Better setup and environment validation
- Ad workflow observability and logs
- Safer deployment defaults for external integrations

## Review expectations

- Small documentation and configuration fixes should be straightforward to review.
- Code changes should include validation notes whenever possible.
- Larger feature work should start with an issue so the direction is clear before implementation.
